# Protected Codex invariant suite

This entire directory is a protected authoritative baseline. Read it whenever
applicable, but do not edit, replace, rename, move, or delete any file during
ordinary project, initiative, implementation, documentation, or validation
work.

An invariant change is permitted only when a human explicitly identifies the
particular revision or addition being authorized. A general request to
implement, align, fix, validate, or complete work is not authorization. An
authorized revision must follow the evidence-authority requirements for
preserving prior state, authority, reason, affected scope, effective point,
compatibility or migration effects, and successor relationships.

Do not refresh `.tadp-lock.json` or use the protected-update commit override
unless the same explicit human authority covers the invariant change. Never
alter the lock merely to hide or accept unexplained drift.
