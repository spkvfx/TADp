# Project-wide decisions

This folder starts with navigation only. Add project-wide decisions here only
when their actual authority and source evidence exist; do not copy TADp's own
development decisions into a new project's history.

Initiative-specific human decisions belong in the owning initiative's
`decision-receipts/` directory. Select the reusable
[decision receipt](../initiatives/decision-receipts/decision-receipt.template.md)
and any required exception fields through the canonical workflow. Templates
provide a record shape, not an answer, approval or historical event.
