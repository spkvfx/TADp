# Proposal record templates

This folder carries reusable shapes for proposal records. Copy
[README.template.md](README.template.md) to the selected initiative's
`proposal/README.md`, [proposal.template.md](proposal.template.md) to its
`proposal/proposal.md`, and use the
[preparation skeleton](preparation-README.template.md) only through Stage 0.
The workflow owns the destination and creation trigger; these sources do not
allocate an initiative or create acceptance evidence.

Retain frozen proposal inputs and source identities. The governing invariant
suite determines their standing; source-template wording cannot override it.
