# Decision receipt templates

These sources supply initiative-local records after an actual decision or
authorized exception occurs. Copy [README.template.md](README.template.md)
to the owning initiative's `decision-receipts/README.md` when the workflow
requires its index. Use [decision-receipt.template.md](decision-receipt.template.md)
for exact human authority and [gate-exception.template.md](gate-exception.template.md)
for the additional per-rule and instruction-block fields.

Do not populate these protected reusable sources or invent decisions from
their presence. Copying this baseline folder installs shapes; it creates no
initiative-local receipt directory, approval or exception.
