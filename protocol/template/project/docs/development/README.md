# Working with the project

This folder contains explanatory guides copied directly into the project.
Use the getting-started, repository-layout, initiative-workflow, requirements
and validation guides for the installed workflow. Commands are examples until
an authorized invocation executes them.

TADp framework development reports and maintenance decisions are not project
work or proof of project adoption. Do not create a fictional project history
from a copied distribution record. Record shapes are supplied separately as
`.template.md` files under the relevant project folders.
