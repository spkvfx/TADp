# Project operation and migration guides

Use these guides to understand the installed workflow and the separate
authority needed to adopt or migrate a revision. Reading or copying a guide
does not execute its commands or change live project records.

Select the applicable guide using the project's recorded governing revision.
Reusable project and initiative record shapes live under `initiatives/` and
the installed `template/project/` baseline; this folder contains explanatory
files copied directly rather than templates to populate.
