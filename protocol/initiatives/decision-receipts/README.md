# Decision receipts

Select sources from the protected template library after an actual decision or
authorized exception occurs. Copy the [index source](../../template/project/initiatives/decision-receipts/README.template.md)
to the owning initiative's `decision-receipts/README.md` when the workflow
requires its index. Use the [decision receipt source](../../template/project/initiatives/decision-receipts/decision-receipt.template.md)
for exact human authority and the [gate exception source](../../template/project/initiatives/decision-receipts/gate-exception.template.md)
for the additional per-rule and instruction-block fields.

Keep reusable sources in `template/`; create only the required populated
instances outside it. This navigation creates no initiative-local receipt
directory, approval or exception.
