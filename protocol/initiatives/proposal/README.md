# Proposal records

Reusable proposal sources live in the protected template library. Copy the
[proposal index source](../../template/project/initiatives/proposal/README.template.md) to the selected initiative's
`proposal/README.md`, the [proposal source](../../template/project/initiatives/proposal/proposal.template.md) to its
`proposal/proposal.md`, and use the
[preparation skeleton](../../template/project/initiatives/proposal/preparation-README.template.md) only through Stage 0.
The workflow owns the destination and creation trigger; these sources do not
allocate an initiative or create acceptance evidence. Keep the reusable sources
in `template/` and populate only the required destination copies.

Retain frozen proposal inputs and source identities. The governing invariant
suite determines their standing; source-template wording cannot override it.
