# Project-wide decisions

Create a project-wide decision here only when its actual authority and source
evidence exist. Initiative-specific decisions belong in the owning
initiative's `decision-receipts/` directory.

Select the [decision receipt source](../template/project/initiatives/decision-receipts/decision-receipt.template.md)
and any required exception fields through the
[canonical coverage map](../template/TEMPLATE-COVERAGE.md). Keep reusable
sources in `template/` and populate only the required destination copies.
