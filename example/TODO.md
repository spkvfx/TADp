# Initiative TODO

Use the [initiative workflow](../protocol/docs/development/initiative-workflow.md) for
the complete requirements. This checklist is a convenience and does not
replace the initiative records or evidence required by that workflow.

- [ ] Prepare the initiative and its dedicated Git branch.
- [ ] Create the proposal from an existing realization.
- [ ] Align the proposal with applicable evidence.
- [ ] Create the complete initial initiative suite.
- [ ] Align the initiative as one coherent specification.
- [ ] Obtain human dispositions for assumptions.
- [ ] Obtain human answers or explicit deferrals for open questions.
- [ ] Align SDK/API surfaces when the initiative is an implementation initiative.
- [ ] Review implementation readiness.
- [ ] Execute the accepted initiative and record the work.
- [ ] Finalize only after the exact completion claim is verified.
