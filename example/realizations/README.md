# Realizations

Realizations are notes that capture an observed opportunity, concern, insight,
or requested outcome. Their primary use is creating or revising proposals.

Treat each stored realization as immutable evidence of what was observed or
proposed at that time. Preserve its source, author when known, date, and
context. Add a linked revision or correction note instead of rewriting it.

A realization is `../evidence/non-authoritative` unless an explicit owning
authority separately classifies it otherwise. It does not become an accepted
initiative requirement merely by being stored or cited.
