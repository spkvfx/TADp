# Repository documentation

These non-authoritative guides explain this checkout and its maintenance.
Projects adopting TADp use the [portable protocol documentation](../protocol/docs/README.md).

| Guide | Reader and responsibility |
|---|---|
| [Repository layout](repository-layout.md) | Checkout structure and ownership boundaries |
| [Developing TADp](developing-tadp.md) | Contributor setup, maintenance prompts, qualification and controlled distribution maintenance |
| [Implementing TADp in projects](implementing-tadp-in-projects.md) | Short adoption entry point to the portable procedure |
| [Development-project workflow](../TADp/docs/development/tadp-development-workflow.md) | Existing project-owned governance and serial delivery contract |

The example is maintained in the separately supplied
[example repository](https://github.com/spkvfx/TADp-example); it is not a required
mirror or validation target. Its behavior and adoption are not asserted here.

The portable documentation split is currently a preparation target,
not a completed rollout. Its [owning preparation record](../TADp/evidence/non-authoritative/documentation-split/preparation.md)
records the source map, evidence and pending decisions. Project decisions and
verification history stay at `TADp/`, outside this repository index.
