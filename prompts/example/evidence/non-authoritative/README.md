# Non-authoritative evidence

Artifacts in this directory are clues, observations, examples,
recommendations, and exploratory analysis. They may resolve ambiguity and
support a decision, but they are not binding.

- Preserve each artifact exactly unless explicitly instructed to change it.
- Cite the artifact and its limits when it supports a proposal, initiative, or
  product assessment.
- It cannot supersede
  [`../authoritative`](../authoritative/README.md).
- When it conflicts with authoritative evidence, retain both records and
  record the conflict rather than silently choosing the non-authoritative
  interpretation.
