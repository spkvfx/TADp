# Decision receipt templates

These sources supply records after an actual decision or authorized exception
occurs. Copy [README.template.md](README.template.md) to the owning initiative's
`decision-receipts/README.md` when the workflow requires its index. Project-owned
items reuse the existing `decisions/README.md` index and this same receipt
source at `decisions/<receipt-id>.md`; no fictional initiative or second receipt
system is needed. Use [decision-receipt.template.md](decision-receipt.template.md)
for exact human authority and [gate-exception.template.md](gate-exception.template.md)
for the additional per-rule and instruction-block fields.

Do not populate these protected reusable sources or invent decisions from
their presence. Copying this baseline folder installs shapes; it creates no
initiative-local receipt directory, approval or exception.

Select each actual owner and destination through TEMPLATE-COVERAGE.md. Preserve
the originating review separately from the canonical item and receipt owner.
Discovery begins unresolved without a fabricated receipt. Record sufficient
exact human authority or attributed covered delegated results before changing
an item disposition; missing authority produces an owned unresolved handoff.
